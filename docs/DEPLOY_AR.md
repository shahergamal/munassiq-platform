# رفع مُنَسِّق على الإنترنت وتحديثه بضغطة زر

دليل لغير المبرمجين. يتم الإعداد مرة واحدة، وبعدها كل تحديث يكون بزر «نشر التحديث» في لوحة الأدمن.

## الفكرة
- **الكود** على GitHub. **السيرفر** عليه برنامج مجاني اسمه **Coolify** يعمل كلوحة تحكم للاستضافة.
- **Coolify** يأخذ الكود من GitHub، ويبني البرنامج، ويشغّله بقاعدة بيانات وشهادة HTTPS.
- **زر «نشر التحديث»** في لوحة أدمن مُنَسِّق يطلب من Coolify أن يبني آخر نسخة. لو فشل البناء، تبقى النسخة الشغالة كما هي.

## ما تحتاجه
- **سيرفر VPS:** بـ 2 جيجا رام على الأقل (4 أفضل)، ونظام Ubuntu 22.04 أو 24.04. من Hetzner أو DigitalOcean أو Contabo، أو مزوّد سعودي.
- **دومين:** مثل `app.example.com`، ويفضّل أن يكون على **Cloudflare**.
- **حساب GitHub** عليه كود المشروع (مستودع خاص).
- **بريد SMTP** لإرسال رسائل التفعيل واستعادة كلمة المرور (مثل Brevo أو Zoho Mail أو Amazon SES).

## 1. تثبيت Coolify (مرة واحدة)
ادخل على السيرفر من الطرفية (Terminal) بالأمر الذي أعطاه لك المزوّد، ثم الصق هذا الأمر:
```bash
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```
بعد انتهائه افتح `http://عنوان-السيرفر:8000` وأنشئ حساب المدير.

## 2. إنشاء المشروع في Coolify
1. **Projects ← New ← Resource ← Private Repository (with GitHub App)**، واربط حساب GitHub واختر المستودع.
2. **Build Pack:** اختر **Docker Compose**، ومسار الملف `deploy/docker-compose.prod.yml`.
3. **في خدمة `web`:** ضع الدومين في **Domains** مثل `https://app.example.com`. Coolify يصدر شهادة HTTPS تلقائياً.
4. **في Environment Variables:** أضف المتغيرات التالية. المطلوبة عليها ★، ولكل كلمة سر أو مفتاح سري اكتب نصاً عشوائياً طويلاً (40 حرفاً أو أكثر):

| المتغير | القيمة |
|---|---|
| ★ `POSTGRES_PASSWORD` | كلمة سر عشوائية طويلة |
| ★ `APP_DB_PASSWORD` | كلمة سر عشوائية أخرى |
| ★ `SYSTEM_DB_PASSWORD` | كلمة سر عشوائية أخرى |
| ★ `SESSION_SECRET` | نص عشوائي 40 حرفاً أو أكثر |
| ★ `APP_URL` | `https://app.example.com` (نفس الدومين) |
| ★ `SMTP_URL` | من مزوّد البريد، مثل `smtps://user:pass@smtp-relay.brevo.com:465` |
| `MAIL_FROM` | `مُنَسِّق <no-reply@example.com>` |
| `ZATCA_KEY_SECRET` | نص عشوائي 40 حرفاً. **لا تغيّره أبداً بعد التشغيل** |
| `PLATFORM_MOYASAR_SECRET_KEY` | المفتاح السري لحسابك في ميسّر، لتحصيل الاشتراكات |
| `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ZONE_ID` | من Cloudflare (الخطوة 5) |
| `DEPLOY_HOOK_URL` / `DEPLOY_HOOK_TOKEN` | من Coolify (الخطوة 4) |
| `ANTHROPIC_API_KEY` | اختياري، للمساعد الذكي المتقدم |

5. اضغط **Deploy**. أول بناء يأخذ 5 إلى 10 دقائق، والبرنامج يجهّز قاعدة البيانات بنفسه.

## 3. أول مدير للمنصة
من Coolify افتح خدمة **api** ثم **Terminal** واكتب:
```bash
node src/scripts/create-admin.ts --email you@example.com --name "اسمك"
```
سيطلب منك كلمة المرور (10 أحرف على الأقل، وتظهر أثناء الكتابة)، اكتبها واضغط Enter. بعدها ادخل على الموقع بهذا البريد، وستجد «إدارة المنصة» في قائمة حسابك.

## 4. ربط زر «نشر التحديث»
1. في Coolify افتح التطبيق، ثم **Webhooks**، وانسخ **Deploy Webhook URL**.
2. من **Keys & Tokens ← API Tokens** أنشئ رمزاً بصلاحية **deploy**.
3. ضع الرابط في `DEPLOY_HOOK_URL` والرمز في `DEPLOY_HOOK_TOKEN`، ثم اضغط Deploy مرة أخيرة من Coolify.

من الآن، كلما رُفع كود جديد إلى GitHub، ادخل **إدارة المنصة ← الخادم والحماية** واضغط **نشر التحديث**.

## 5. Cloudflare
1. انقل الدومين إلى Cloudflare، واجعل سجل `app` بالسحابة البرتقالية (Proxied) موجهاً لعنوان السيرفر.
2. من **SSL/TLS** اختر **Full (strict)**.
3. **أنشئ رمز API:** من **My Profile ← API Tokens ← Create Token ← Custom**:
   - الصلاحيات: `Zone → Cache Purge → Purge` و`Zone → Firewall Services → Edit`.
   - النطاق (Zone Resources): دومينك فقط.
4. ضع الرمز في `CLOUDFLARE_API_TOKEN`، و**Zone ID** (من صفحة Overview للدومين) في `CLOUDFLARE_ZONE_ID`.
5. بعدها تعمل من لوحة الأدمن: مسح الكاش، وحظر العناوين المشبوهة، وإلغاء الحظر.

## ماذا تفعل الأزرار في «الخادم والحماية»
- **نشر التحديث:** يبني آخر نسخة ويستبدل بها الحالية (2 إلى 5 دقائق)، والموقع يعمل أثناء البناء.
- **إعادة تشغيل الخادم:** يوقف البرنامج بهدوء ثم يعود خلال ثوانٍ. Docker يعيد تشغيله تلقائياً.
- **مسح الكاش:** بعد التحديث، إن ظهرت للزوار النسخة القديمة.
- **عناوين مشبوهة:** كل عنوان حاول الدخول بكلمات مرور خاطئة كثيراً، أو أرسل طلبات كثيرة جداً. زر **حظر** يمنعه عبر Cloudflare. لا يمكنك حظر عنوانك الحالي بالخطأ.

## النسخ الاحتياطي (مهم)
في Coolify افتح خدمة **db** ثم **Backups**، وفعّل نسخة يومية. يفضّل إرسالها إلى مساحة خارجية (S3 أو Cloudflare R2).
